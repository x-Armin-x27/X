# One UI 8 Launcher — پروژه آغازین برای Galaxy A52s

این پروژه یک لانچر اندرویدی مستقل و قابل توسعه است؛ رام یا سیستم‌عامل گوشی را تغییر نمی‌دهد.

## امکانات پیاده‌سازی‌شده در نسخه 1.0
- ثبت Activity به‌عنوان گزینه Home Launcher اندروید
- صفحه اصلی با ساعت و تاریخ
- فهرست برنامه‌های نصب‌شده با آیکون واقعی هر برنامه
- جست‌وجوی برنامه‌ها
- اجرای برنامه‌ها با لمس آیکون
- تغییر ساده بین تم روشن و تاریک
- باز کردن انتخابگر/تنظیمات تصویر پس‌زمینه اندروید

## محدودیت‌های این نسخه
- ساعت و تاریخ در این نسخه با بازشدن صفحه نمایش داده می‌شوند؛ به‌روزرسانی زنده و ویجت سیستمی هنوز اضافه نشده است.
- کارت آب‌وهوا فعلاً نمایشی است و به سرویس آب‌وهوا متصل نیست.
- ساخت پوشه، جابه‌جایی آیکون‌ها، ویجت‌های واقعی، انیمیشن‌های پیشرفته و بسته آیکون اختصاصی هنوز پیاده‌سازی نشده‌اند.
- ظاهر، الهام‌گرفته از One UI است و کپی رسمی یا نرم‌افزار سامسونگ نیست.

## ساخت APK
نیاز است پروژه با Android Studio یا یک سرویس ساخت اندروید سازگار باز و Build شود.
- JDK 17
- Android SDK 35
- Android Gradle Plugin 8.7.3
- Gradle سازگار با AGP 8.7.3

در Android Studio:
1. پوشه پروژه را باز کن.
2. صبر کن Gradle Sync تمام شود.
3. از منوی Build گزینه Build APK(s) را انتخاب کن.
4. خروجی debug معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

## تنظیم لانچر پیش‌فرض
پس از نصب APK، دکمه Home را بزن و One UI 8 Launcher را انتخاب کن؛ یا از تنظیمات اندروید، Apps > Default apps > Home app را باز کن.

## نکته دسترسی برنامه‌ها
برای فهرست‌کردن برنامه‌های نصب‌شده از `QUERY_ALL_PACKAGES` استفاده شده است. این دسترسی برای نصب جانبی قابل درخواست است، اما انتشار در Google Play تابع سیاست‌های آن فروشگاه است.
